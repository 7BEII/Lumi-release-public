# Lumi 光颜

Windows 桌面版 · AI 人像与写真创作

**[下载安装包](https://github.com/7BEII/Lumi-release-public/releases/latest/download/Lumi-Setup-1.0.5.exe)** · [全部版本](https://github.com/7BEII/Lumi-release-public/releases) · [安装说明](安装说明.md)

## 安装

1. 下载 `Lumi-Setup-1.0.5.exe`，双击打开。
2. 选择安装位置，点击“安装”。
3. 完成时勾选“立即打开 Lumi”和“添加桌面快捷方式”。
4. 以后双击桌面的“Lumi 光颜”即可。

适用于 64 位 Windows 电脑。安装包不内置生图 API Key，首次使用需在程序设置中填写自己的有效 Key。
